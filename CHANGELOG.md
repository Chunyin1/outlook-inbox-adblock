# Changelog

## 0.1.0

Initial public release for new Outlook on Windows.

- Reversible IPv4/IPv6 hosts rules for three advertising endpoints.
- Optional local helper to hide the Microsoft Upgrade card, with explicit acceptance of the debugging-access risk.
- Document-start CSS to prevent the brief card flash on the tested layout.
- Per-user startup, install/repair, status, and uninstall commands.
- Synthetic browser and Windows configuration tests, with Windows CI.

See README.md for tested versions, installation instructions, and compatibility limitations. Read SECURITY.md before enabling full filtering.
